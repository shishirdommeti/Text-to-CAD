# Text-to-CAD

This repository contains all work done towards a physics-aware text to CAD generation model. Each folder has the following contents:
*  **CADFusion-Benchmark**: Implemented Microsoft's LoRA finetuned CADFusion model for a baseline of existing text to CAD models.
*  **Gemma3-12B Benchmark Pipeline**: Created a generation pipeline for a Gemma3-12B, a larger parameter open source model, aiming to compare larger base models with smaller finetuned models.
*  

Currently exploring finetuning methods to attempt injecting physics awareness into a larger parameter base model.
